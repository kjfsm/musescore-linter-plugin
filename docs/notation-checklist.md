# 楽譜浄書チェック項目カタログ

楽譜浄書（engraving）の観点で、本プラグインに追加しうるチェック項目のカタログ。
作るものは A〜J に、作らないものは理由とともに「作らないもの」に置く。

## 方針

- MuseScore の自動チェックで回避できるもの（拍合計の不一致、音域逸脱など）は **優先度低 / 対象外**。
- 「その書き方は基本的に間違い」（休符にフォルテ 等）を重視。
- **弦楽器以外**（木管・金管・鍵盤・ハープ・打楽器・声楽）に範囲を広げる。
- 音域は MuseScore で見られるので不要。
- 他の浄書チェックプラグイン（MN Better Notation Plugins など）との併用は前提にしない。
  それでも扱わない観点は「作らないもの」に理由を書く。

## 作るかどうかの基準

上から順に当て、最初に当たったもので決める。

1. **`Score` で表せないものは作らない。** レイアウト・フォント・スタイル設定・手で動かした位置・符幹や連桁の設定は、
   MusicXML から同じ値を取れない。ルールが `score-model` だけを見る構成（`AGENTS.md`）と、
   2 つの reader が同じ `Score` を返すという約束（conformance テスト）が崩れる。
2. **MuseScore が入力の段階で防ぐものは作らない。**
3. **楽器の物理的な制約を知らないと判定できないものは作らない。** 楽器ごとの表（弦の調弦・ハーモニクスの音・
   ハープのペダル・手の届く幅・演奏できる速さ）を持つ費用に見合わず、誤検出も多い。
4. **好みや閾値で決まるものは作らない。** 「基本的に間違い」と言えず、指摘がノイズになる。
5. **`Score` に情報を足すのは、足したもので複数の項目が作れるときだけ。**

## タグ凡例

| タグ    | 意味                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------ |
| `NOW`   | 今の `Score`（`packages/score-model/src/types.ts`）だけで実装可能                                      |
| `MODEL` | `Score` に情報を足す必要がある（`score-model` の型と、両方の reader の変更）。必要なデータを備考に明記 |
| `MS`    | MuseScore が自動で検出できる → 優先度低 or 対象外                                                      |
| ✅      | 実装済み                                                                                               |

## 今の Score で取れるデータ（実装可否の根拠）

- **取れる**: パート（id・名前・譜表）、譜表ごとの声部の chord / rest（tick・小節・音価・連符かどうか・
  音高・tpc・譜表位置・臨時記号の表示・アーティキュレーション名）、小節線の種類（二重線・終止線・
  リピート開始/終了/両方）、小節（通し番号・表示上の番号・長さ・拍子）、スラー・タイ（両端の音高つき）・ヘアピン、
  システムブラケット、注記（テキストと、解釈済みの奏法・強弱・テンポ・反復記号・リハーサルマーク）。
- **取れない**: 調号、音部記号、楽器メタ情報（楽器族・移調・MIDI program・有/無音程）、連符の比率、
  装飾音、歌詞、グリッサンド/トレモロ、符幹の向き・連桁の設定、休符のフェルマータ。
- **reader で揃っていない**: アーティキュレーション名。MuseScore 経由では UI 言語の名前（「上スタッカート」など）が入り、
  MusicXML 経由の名前（`Accent` など）と一致しない。名前で種類を判定するルールは今は書けない。

`Score` に足すときは、`score-model` の型を変えたうえで `reader-musicxml` と `reader-musescore` の両方で
埋め、`packages/reader-musescore/tests/conformance.test.ts` で同じ値になることを確かめる。

## 作らないもの

A〜J から外した項目と、[MN Better Notation Plugins for MuseScore](https://github.com/mnorrisvuw/MN-Better-Notation-Plugins-for-MuseScore)
（v1.4）のチェック項目のうち作らないもの。数字は上の「作るかどうかの基準」。

| 項目                                                                                                                                         | 基準 | 理由                                                                                     |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------------------------- |
| 譜表サイズ・余白・間隔・小節幅・用紙・最終段の位置・表紙・ページ番号など、レイアウトとスタイル設定全般                                       | 1    | `Score` に無い。MusicXML の値は MuseScore の設定と対応しない                             |
| 譜表名・譜表の順序・楽器名の表記                                                                                                             | 1    | パート名以外の譜表の表示設定が無い                                                       |
| フォント・テキストスタイル・太字・音価記号の大きさ・未インストールのフォント                                                                 | 1    | 同上                                                                                     |
| 手で動かした要素（スラー・連桁・連符数字・ヘアピン・符尾・符頭）、衝突、leading space、stretch                                               | 1    | 自動位置からのずれは MuseScore だけが持つ                                                |
| 符幹の向き・連桁のつなぎ方（F5、連桁の過不足、内側の連桁）                                                                                   | 1    | 同上                                                                                     |
| タイトル・副題・作曲者が既定値のまま                                                                                                         | 1    | 楽譜のメタ情報を持たない。足しても項目が 1 つしか増えない（基準 5）                      |
| 小節線をまたぐ音価（F2）、休符をまたぐタイ、アウフタクトの休符の食い違い、手で入力した全休符                                                 | 2    | MuseScore が入力の段階で分割・揃える                                                     |
| ペダル記号のテキスト（C12）                                                                                                                  | 2    | MuseScore のペダルラインを使えば要らない                                                 |
| 弦のハーモニクス・重音・弓記号・1 弓の長さ、ハープの和音とペダル（H4）、鍵盤の手の届く幅、トロンボーンのグリッサンド、演奏できない速さ・跳躍 | 3    | 楽器ごとの表が要る                                                                       |
| 移調楽器の記譜（D7・H3）、無音程楽器（H6）、管楽器の 1./a 2、単旋律楽器のポリフォニー、太鼓のトレモロ                                        | 3・5 | 楽器メタ情報を足しても、各項目に楽器ごとの表が要る                                       |
| 歌詞（H7・H8、声楽の各項目）                                                                                                                 | 5    | 歌詞を足しても声楽にしか効かない                                                         |
| トレモロ・グリッサンド・装飾音（D4・I1〜I3）                                                                                                 | 5    | 種類ごとに型が要り、それぞれ 1 項目しか作れない                                          |
| 長い連続音のブレス（H1）、ピアノ両手の声部（H5）                                                                                             | 4    | 閾値や書き方の好みで決まる                                                               |
| `sf` 等の単独連続（A7）、アクセントの無い `sf`、短すぎるヘアピン、強弱の無い長いパッセージ、`cresc.` テキストかヘアピンか                    | 4    | 好みで決まる                                                                             |
| 強弱記号の位置、誤った対象の強弱記号、音域に合わない強弱、実現できない複合強弱                                                               | 1・4 | 位置を持たない。残りは好み                                                               |
| 極端なテンポ、`c.` か `approx.` か、テンポが 1 拍目に無い、速度語の無いメトロノーム記号、メトロノーム記号の括弧や空白                        | 4    | 好みで決まる。拍の途中のテンポ変更は正しい書き方でもある                                 |
| `rit.` と `accel.` などの異なるテンポ変化が新しいテンポを挟まず続く                                                                          | 4    | 「poco rit. … molto rit.」のように段階を書くのは正しい。同じ表記の重ね書きだけ B5 で見る |
| 綴りの誤り・大文字小文字・先頭の空白・省略できる語・引用符                                                                                   | 4    | 語の辞書を持つ費用に対して、表記の好みと区別しにくい                                     |
| セクション境界のリハーサルマーク（E6）、最初の 2 小節のリハーサルマーク                                                                      | 4    | 置くかどうかは好み                                                                       |
| スラーの入れ子、スラー途中のアクセント、スラー内の同音反復、スラーもアーティキュレーションも無い長いパッセージ                               | 4    | 正しい書き方でもある。同じ音高の 2 音だけのスラーは G2 で見る                            |

| フラッター（C14）、vibrato（C15）、bisbigliando（C16）                                                                                       | 4    | 明示的な解除を持たないので on/off で判定できない、またはノイズになる                     |
| 音部記号（楽器が読まない・重複・タイの途中の変更・ホルンのヘ音記号など）                                                                     | 3・5 | 音部記号を足しても、多くは楽器ごとの表が要る。足すなら調号の次                           |
| 拍子記号の欠落・重複                                                                                                                         | 2    | MuseScore と MusicXML の書き出しが拍子を揃える                                           |
| 増減音程の連続、半音階の綴り                                                                                                                 | 4    | 和声の文脈で正誤が変わる                                                                 |
| 親切臨時記号の括弧                                                                                                                           | 1・4 | 括弧の有無を持たない。付けるかは好み                                                     |
| 連符の比率の表示・複雑な連符（F4 の具体化）                                                                                                  | 5    | F4 に置いた。比率を足すかは F4 で決める                                                  |

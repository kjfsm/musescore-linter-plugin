# 楽譜浄書チェック項目カタログ

楽譜浄書（engraving）の観点で、本プラグインに追加しうる **チェック項目の網羅カタログ**。
次ステップで取捨選択・優先度確定・実装する前提で、**実現できないものや優先度の低いものもあえて残してある**。

## 方針

- MuseScore の自動チェックで回避できるもの（拍合計の不一致、音域逸脱など）は **優先度低 / 対象外**。
- 「その書き方は基本的に間違い」（休符にフォルテ 等）を重視。
- **弦楽器以外**（木管・金管・鍵盤・ハープ・打楽器・声楽）に範囲を広げる。
- 音域は MuseScore で見られるので不要。

## タグ凡例

| タグ    | 意味                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------ |
| `NOW`   | 今の `Score`（`packages/score-model/src/types.ts`）だけで実装可能                                      |
| `MODEL` | `Score` に情報を足す必要がある（`score-model` の型と、両方の reader の変更）。必要なデータを備考に明記 |
| `MS`    | MuseScore が自動で検出できる → 優先度低 or 対象外                                                      |
| ✅      | 実装済み                                                                                               |

## 今の Score で取れるデータ（実装可否の根拠）

- **取れる**: パート（id・名前・譜表）、譜表ごとの声部の chord / rest（tick・小節・音価・連符かどうか・
  音高・tpc・譜表位置・臨時記号の表示・アーティキュレーション名）、小節線の種類（二重線・終止線・
  リピート開始/終了/両方）、小節（通し番号・表示上の番号・長さ・拍子）、スラー・タイ（両端の音高つき）・ヘアピン、
  システムブラケット、注記（テキストと、解釈済みの奏法・強弱・テンポ・反復記号・リハーサルマーク）。
- **取れない**: 調号、音部記号、楽器メタ情報（楽器族・移調・MIDI program・有/無音程）、連符の比率、
  装飾音、歌詞、グリッサンド/トレモロ、符幹の向き・連桁の設定。

`Score` に足すときは、`score-model` の型を変えたうえで `reader-musicxml` と `reader-musescore` の両方で
埋め、`packages/reader-musescore/tests/conformance.test.ts` で同じ値になることを確かめる。

## K. 未仕分けの候補（MN Better Notation Plugins 由来）

[MN Better Notation Plugins for MuseScore](https://github.com/mnorrisvuw/MN-Better-Notation-Plugins-for-MuseScore)
（v1.4、README の列挙）のチェック項目のうち、A〜J に無いもの。タグ・severity・優先度は未判定で、
仕分けたら該当カテゴリへ移す。A〜J の既存項目を具体化するものは `→` で示す。

### リズム / 連桁

- 1 つの音符にまとめられるタイ
- 1 つにまとめられる休符
- 手で入力した全休符
- 連桁でつなぐべき音がつながっていない / つなぐべきでない音がつながっている
- 切るべき内側の連桁
- スタッカートで書いたほうがよい音符
- 拍子が見えるように書くべき休符 → F1
- 比率の表示が必要な非標準の連符 → F4
- 複雑すぎる・誤解を招く連符 → F4
- 分子と分母が同じ連符 → F4
- 不要な連符（付点 4 分 2 つに 3 連符の括弧など） → F4
- アウフタクトの休符がパート間で食い違う

### 臨時記号 / 綴り

- 増減音程が続く（綴り間違いの兆候）
- 極端な臨時記号（B# Cb E# Fb。調号を考慮） → J3
- 半音階の上行・下行の綴り
- 親切臨時記号の不要な括弧
- 同じ音高が続くのに綴りが違う → J4

### ダイナミクス

- 強弱記号の位置が不適切
- 長い休符のあとに強弱を言い直していない
- ヘアピンの代わりに `cresc.`/`dim.` テキストを使っている
- 強弱記号の無い長いパッセージ
- ヘアピンが正しい位置から動かされている
- 重なったヘアピン
- 短すぎるヘアピン
- アクセントの無い `sf` → A7
- 実現できない複合強弱（`sfzp` など）
- 誤った対象に付いた強弱記号
- 音域によっては不適切な強弱記号

### テンポ

- テンポ表記を Tempo テキストで入れていない
- `rit.`/`accel.` が新しいテンポを挟まず連続する
- テンポ表記が大きすぎる / 小さすぎる、メトロノーム記号が太字、テンポ語が太字でない
- `approx.` でなく `c.` を使う
- メトロノーム記号の重複
- メトロノーム記号の不要な括弧、`=` の前後に空白が無い、フォントの混在、音価記号が大きすぎる
- 冒頭のメトロノーム記号に速度語が無い
- テンポ表記が 1 拍目に付いていない
- 極端に速い / 遅いテンポ

### テキスト

- よくある綴りの誤り
- 大文字小文字の誤り
- 先頭の空白や記号
- 省略できる語
- 表情記号の位置が不適切
- ストレートな引用符
- タイトル・副題・作曲者が既定値のまま
- 奏法テキストの位置が不適切
- 手で動かした連符数字

### リハーサルマーク

- リハーサルマークが無い → E6
- 最初の 2 小節にリハーサルマーク
- リハーサルマークが 1 拍目に付いていない

### スラー

- タイの付いた音でスラーが始まる / 終わる
- スラー内の同音反復にアーティキュレーションが無い
- スラーの途中のアクセント
- スラーの入れ子
- 同じ音に複数のスラー
- スラーもアーティキュレーションも無い長いパッセージ
- 手で入れた / 自動位置から動かしたスラー
- 2 音トレモロにスラーが無い

### 調号 / 拍子 / 音部記号 / オクターブ

- 極端な調号（6 つ以上）
- 調号がすぐに変わる
- 重複した調号の変更
- 不必要に複雑な調号
- 最初の拍子記号が無い
- 重複した拍子記号
- 楽器が読まない音部記号
- 重複した音部記号
- 読みやすくなる音部記号の変更が無い
- 音部記号の変更の位置が悪い
- 声種に合わない音部記号
- タイの途中で音部記号を変更
- 8va/8vb の誤用・不要・必要、不要な 22ma/22ba
- ホルンを不必要にヘ音記号で書いている
- ホルンのパートに調号
- ハープ・マリンバの不要な音部記号変更
- 移調譜表がオンになっていない → D7

### 弦楽器

- arco に見えるのに `pizz.` と書かれている
- ハーモニクスの記譜の誤り、存在しないハーモニクス、人工ハーモニクスの音程の誤り・高すぎる
- ダイヤモンド符頭とハーモニクスの丸を併用している
- タイで結んだハーモニクスに丸が無い
- 1 弓に収まらない・強弱に対して長すぎるスラー
- `pizz.` の長い音、`pizz.` にスタッカート
- 不適切なスラースタッカート
- 指トレモロにスラーが無い、弓トレモロにスラーが付いている
- 同じ弦で 2 音を弾く重音
- 3・4 重音を全弦で伸ばしている
- 不可能な重音
- 速い重音のパッセージ
- 不要かもしれない孤立した弓記号
- 弦楽器以外に弓記号
- `pizz.`⇔`arco` の切り替えが速すぎる

### ハープ

- ダブルフラット / ダブルシャープ
- 不可能な和音、和音の音が多すぎる
- 速いペダル変更が多すぎる → H4
- スラースタッカート

### 鍵盤

- 手の届かない広がり
- ペダル記号が無い
- full pedal の連続（踏み直しで済む）
- `Ped.` 記号を使っていない → C12

### 管楽器 / 打楽器 / その他の楽器

- 管楽器の共有譜表で単旋律に `1.`/`a 2` が無い
- フルートのハーモニクスの記法
- フラッタータンギングの記法 → C14
- 直線と波線のグリッサンドの誤用
- トロンボーンで不可能なグリッサンド
